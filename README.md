Welcome to **Republic TV** (formerly Game Republic TV)—your custom-built, next-generation IPTV streaming experience. This project serves as the central hub for high-quality M3U playlists, automated stream aggregation, and perfectly synced Electronic Program Guides (EPG).

## ✨ Features

* **Dynamic M3U Playlists:** Continuously updated streaming links parsed automatically for maximum uptime and seamless viewing.
* **Rich EPG Integration:** Custom XMLTV-generated metadata ensures you always know what's playing, complete with accurate scheduling and TMDB-sourced program info.
* **Broad Device Compatibility:** Works flawlessly with any standard IPTV player (TiviMate, IPTV Smarters, VLC, etc.) across mobile, desktop, and smart TVs.
* **Automated Backend:** Powered by reliable Python scrapers and customized PHP engines to keep the stream catalog fresh 24/7.

## 🚀 How to Use

1. Download your preferred IPTV Player application.
2. Add a new playlist using the **M3U URL** provided in this repository (or your dedicated deployment link).
3. Add the **EPG Source URL** (XMLTV format) in your app's settings to populate the channel guide.
4. Grab some popcorn and enjoy! 🍿
